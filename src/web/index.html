Load the reference case or list the items recovered from the scene, then run triage.

Division of responsibility. The language model (IBM Bob / watsonx Granite) only reads the free text and returns structured, classified items. It never assigns a number. The priority score, ranking and urgent/non-urgent decision are computed entirely in deterministic Python — the same input and the same ruleset version always produce the identical schedule, stamped with the ruleset’s SHA-256 hash for court traceability. This page calls the /triage API when the server is running, and otherwise falls back to an in-browser mirror of the same engine and ruleset. Decision-support only — it does not replace the examiner or the chain of custody.
